| Tolerance (Tol) | number |  | Residual force relative to the largest force |

| Output | Type | Unit | Description |
|---|---|---|---|
| Lines (L) | curve, list |  | Lines in their equilibrium position |
| Points (P) | point, list |  | Node positions |

_Example:_ Grid of lines + upward load + corner anchors -> gridshell shape

## Optimization

### Evolutionary Optimizer

Searches slider values that minimize (or maximize) a number. Select this component, choose the sliders it may change in the inspector, then press Run. Uses a genetic algorithm with an optional local search, and keeps the best designs so any of them can be reinstated.

| Input | Type | Unit | Description |
|---|---|---|---|
| Fitness (F) | number |  | The number to minimize or maximize |

| Output | Type | Unit | Description |
|---|---|---|---|
| Fitness (F) | number |  | The current fitness value |

_Example:_ Mass + penalty -> Fitness; sliders for depth and width as genes

## Script

### Script

Runs your own JavaScript in a sandboxed worker (no page, storage or network access). Inputs are available as variables holding the whole list for each branch; assign your results to the output variables. Helpers: pt(x, y, z), line(a, b), polyline(points, closed). Edit the code and the port names in the inspector.

Inputs and outputs depend on the settings of the component (see its description).

_Example:_ Custom formula over lists

### Cluster
